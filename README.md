# Vocab 1935 v9 ― 通常学習＋ポイント制

元の1935語を収録。これまでの3回クリア学習は残し、**新しい「ポイント制」タブ**を追加しました。

## ポイント制のルール

1. 全1935語は **0点・未出題**から開始（通常学習の進捗とは完全に別）。
2. 初めて単語が**画面に出た瞬間にロック解除**します。この初回出題の正誤では得点が動きません。
3. 2回目以降は正解なら+1、不正解なら-1。下限なし。例えば-2点なら正解3回で+1点に到達します。
4. **+1点を獲得した単語は合格して以後出題されません**。
5. +1点未満の単語から **1語ずつ等確率でランダム抽選**します。得点/直前の正誤/経験回数による重みも、誤答専用の再出題キューもありません（偶然の連続出題はあり得ます）。
6. 多義語はその回ごとに意味を1つ選択。**先頭の意味は約65%の確率**、その他は残り35%を均等配分。単語のポイントは意味数に関係なく1つだけです。
7. 英→日／日→英／ごちゃまぜの3方向に対応。4択で正解を選ぶと、**正解・誤答の4つすべてに対応する英単語／日本語の意味**が表示されます。

- ポイント制は独立した `vocab1935-points-v1` に保存します。

## GitHub Pagesに設置

1. このフォルダの**中身全部**を既存の公開リポジトリのルートに上書きアップロードします。フォルダ階層を新しく増やさないでください。
2. 公開後はiPhoneのホーム画面のPWAを一度終了して再度開いてください。Service WorkerキャッシュIDは `vocab1935-v9-point-daily-goal` です。
3. 下部の「★ ポイント制」を選んで「ポイント制を始める」を押します。
4. 「記録」タブから通常学習／ポイント制の両進捗をJSON書き出しできます。

GitHubリポジトリは公開ファイルのみを置きます。学習記録は端末内に残り、GitHubへ送信されません。バックアップを取り、別ブラウザ・別URLの進捗は自動共有されない点に注意してください。

## v9: 1935ポイント到達期限と日次ノルマ

- 全1935語の得点を合計した「現在の合計pt」を表示。正の得点は各語最大1点、負の得点の下限なし。全語合格した瞬間にちょうど**1935pt**です。
- **残りpt = 1935 − 現在の合計pt**。未合格語に−5ptがあれば、その単語を合格にするには6pt必要であり、残りptに反映されます。合計ptが負なら残り必要ptは1935を超えます。
- ポイント制専用の**目標日・ノルマ（正味pt/日）**を追加。目標日を含む日数で残りptを割り、切り上げた必要ペースを表示し、1タップでノルマを設定できます。
- **今日の正味ポイント = 今日の（2回目以降の正解＋1）−（2回目以降の不正解−1）**。初回は変動なし。本日の正味合計がノルマ以上なら「今日のノルマ達成」画面に切り替わり、終了または続行を選べます。
- 日付が変わると今日の正味ptは0から始まります（累計点はそのまま）。誤答で今日の合計がマイナスになる場合、ノルマまでの道のりが増えます。
- 元の通常学習の目標日とノルマは**別管理**です。ポイント学習記録 (`vocab1935-points-v1`) はそのまま移行します。日別ポイント履歴だけ `vocab1935-points-days-v1` に独立保存し、JSONバックアップに追加。
- v8から更新した場合、以前のポイント累計はそのまま維持されますが、日別の正味ポイントはv9導入以降に記録されます。過去の日別増減を遡って再構成はできません。
