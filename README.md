# Vocab 1935 v3 — One Daily Mission

1935語の英単語データを、1つの学習ルートだけで進めるiPhone / iPad / PC向けPWAです。外部APIは不要で、学習記録は端末の `localStorage` に保存されます。

## 学習ルール

- 1935語を、元データの番号付き意味ごとに分解します。
- 学習単位は合計 **3553語義**。
- 各語義を3回正解するとクリアなので、全クリまでの有効正解は **10,659回**。
- 4択は全範囲から自動出題します。
- 多義語は `agree ①`, `agree ②`, `agree ③` のように別の学習単位として扱います。
- 同じ英単語の別語義は同じ4択には出しません。さらに、意味がほぼ重複する選択肢も可能な範囲で除外します。
- 不正解で正解回数は減りません。間違えた語義は4〜6問ほど後に自動再出題します。
- 誤答の多い語義は、通常のランダム出題で少し選ばれやすくなります。

## 目標日と1日ノルマ

目標日を設定すると、残っている有効正解数を残り日数で割り、必要な `正解/日` を自動計算します。1日のノルマも単語数ではなく **有効正解数** で管理します。

## GitHub Pages

1. このフォルダ内をGitHubリポジトリのルートへアップロードします。
2. `Settings > Pages` で `Deploy from a branch` を選択します。
3. `main` / `/(root)` を指定します。
4. iPhone / iPadではSafariで公開URLを開き、「ホーム画面に追加」でPWAとして使えます。

`.nojekyll` はそのまま置いてください。

## v2からの進捗引き継ぎ

同じ `localStorage` のキーを使うため、通常の正誤・お気に入り・目標日は引き継ぎます。旧3回クリア記録は、単一語義の単語ではそのまま移行し、多義語では意味別の正解記録だけを安全に移行します。多義語の旧「単語単位3回正解」は、どの意味を答えた記録か判別できないため自動加算しません。
