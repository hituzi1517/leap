# Vocab 1935 PWA

アップロードされた1935語の英単語データを使う、iPhone / iPad / PC向けの英単語学習PWAです。外部APIは不要で、学習データは端末の `localStorage` に保存されます。

## 主な機能

- 1〜1935の範囲指定、100語ごとのプリセット
- 単語カード + 「苦手 / 微妙 / 覚えた」の間隔反復
- 英→日、日→英、スペル入力テスト
- 多義語「意味を全部選ぶ」テスト
- 多義語「意味① / ② ...」を品詞つきで個別に問う意味別ドリル
- 通常テストで間違えた問題を数問後に自動再出題
- 目標日、1日の新規ノルマ、必要ペースの自動計算
- 「今日のノルマ」学習（新規 + 復習）
- 全1935語からランダム出題し、各語3回正解でクリアする長期チャレンジ
- 学習連続日数、直近7日、正答率、多義語定着、100語ごとの習得率
- 検索、お気に入り、発音読み上げ
- JSONで進捗バックアップ / 復元
- ダークモード
- Service Workerによるオフライン利用

## GitHub Pages で公開

1. このフォルダ内のファイルをGitHubリポジトリのルートへアップロードします。
2. GitHubの `Settings > Pages` を開きます。
3. `Deploy from a branch` を選択し、`main` / `/(root)` を指定します。
4. 発行されたURLをSafariで開き、iPhone / iPadでは共有メニューから「ホーム画面に追加」を選びます。

`.nojekyll` はそのまま置いて構いません。

## データ保存について

単語データ、学習ロジック、画面はすべて端末側で動きます。進捗はブラウザのlocalStorageに保存されるため、ブラウザデータを消すと進捗も消えます。定期的に「進捗を書き出す」でJSONバックアップを保存してください。
